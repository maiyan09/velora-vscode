# Changelog

All notable changes to Velora will be documented in this file.

## [0.1.0] - Initial Release

### Added

- Velora Dark and Light color themes
- Minimalist file icon theme
- Editor typography presets
- Focus Mode powered by VS Code Zen Mode
- Appearance Control Center
- First-run welcome screen
- Manual onboarding reset command

### Notes

- Custom font distribution is planned for a future release.
- Additional icon designs and appearance customization are planned.
